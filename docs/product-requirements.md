# 智能睡眠监测台灯 - 产品需求文档 (PRD)

> **产品待决策**：当前 `pages/index/index.tsx` 与 `pages/light/index.tsx` 各自定义了一套灯光场景参数。本 PRD 保留产品意图，但场景数值在两处实现统一前不作为唯一验收契约。

## 一、产品概述

### 1.1 产品定位
集睡眠监测、智能照明、健康辅助于一体的智能家居设备微信小程序。

### 1.2 设计风格
- **UI风格**: 玻璃拟态2.0 (Glassmorphism 2.0)
- **主题色调**: 柔和渐变，以黄色/暖色调为主
- **整体氛围**: 温馨、舒适、助眠

---

## 二、页面结构

| 页面 | 功能模块 | 说明 |
|------|---------|------|
| 首页 | 灯光控制、闹钟、实时体征 | 核心功能页面 |
| 历史数据 | 心率/呼吸趋势图表 | 数据展示页面 |

## 三、首页详细需求

### 3.1 灯光控制模块

#### 3.1.1 功能列表
- [ ] 开关控制
- [ ] 亮度调节 (0-100%)
- [ ] 色温调节 (暖光-冷光)
- [ ] 实时模拟预览
- [ ] 预设场景

#### 3.1.2 预设场景

| 场景 | 亮度 | 色温 | 说明 |
|------|------|------|------|
| 阅读模式 | 70% | 中性偏暖 | 适合阅读学习 |
| 睡眠模式 | 10% | 暖光 | 助眠氛围 |
| 放松模式 | 40% | 柔和暖光 | 放松身心 |
| 工作模式 | 90% | 冷光 | 专注工作 |

#### 3.1.3 交互细节
- 拖动滑条时实时显示灯光预览效果
- 滑条释放后发送指令到设备
- 点击预设场景一键切换

### 3.2 闹钟模块

#### 3.2.1 功能列表
- [ ] 添加闹钟
- [ ] 编辑闹钟
- [ ] 删除闹钟
- [ ] 启用/禁用闹钟
- [ ] 重复周期设置
- [ ] 光闹钟支持

#### 3.2.2 闹钟属性
- 时间 (时:分)
- 重复周期 (每天、工作日、周末、自定义)
- 闹钟类型 (普通闹钟、光闹钟)
- 光闹钟渐变时长（当前页面支持 10/15/20/30 分钟）
- 标签 (可选)

#### 3.2.3 光闹钟逻辑
- 唤醒前N分钟开始灯光渐变
- 从0%亮度逐渐增加到设定亮度
- 色温从暖光逐渐过渡
- 到达设定时间时播放提示音

### 3.3 生命体征卡片

#### 3.3.1 功能列表
- [ ] 心率实时显示
- [ ] 呼吸率实时显示
- [ ] 数据状态指示
- [ ] 异常状态提示

#### 3.3.2 显示内容
- 心率: XX 次/分
- 呼吸: XX 次/分
- 状态: 正常/偏高/偏低

## 六、UI/UX设计规范

### 6.1 玻璃拟态风格

#### 视觉要素
- **背景**: 渐变背景 (如: linear-gradient(135deg, #f093fb 0%, #f5576c 100%) 或 linear-gradient(135deg, #ffecd2 0%, #fcb69f 100%))
- **卡片**: 半透明背景 (rgba(255, 255, 255, 0.15))
- **边框**: 半透明白色边框 (1px solid rgba(255, 255, 255, 0.2))
- **模糊**: backdrop-filter: blur(10px)
- **阴影**: 柔和阴影 (box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1))

#### 组件样式
- **圆角**: 16-24px
- **间距**: 16-24px
- **过渡**: 0.3s ease

### 6.2 色彩系统

| 用途 | 颜色值 |
|------|--------|
| 主背景 | #2d1b0e |
| 卡片背景 | rgba(255, 255, 255, 0.1) |
| 主文本 | #ffffff |
| 次要文本 | rgba(255, 255, 255, 0.7) |
| 强调色 | #f59e0b |
| 成功色 | #10b981 |
| 警告色 | #f97316 |
| 错误色 | #ef4444 |

### 6.3 字体搭配
- **标题**: Manrope Bold
- **正文**: Inter Regular
- **数字**: Manrope Medium

### 6.4 底部导航

| 标签 | 图标 | 页面 |

| 首页 | 🏠 | 首页 |

## 七、技术实现要点

### 7.1 实时模拟
- 拖动滑条时前端实时渲染灯光效果
- 使用CSS渐变模拟不同色温
- 使用opacity/filter模拟亮度变化

### 7.2 数据通信
- MQTT实时推送体征数据
- WebSocket保持长连接
- 本地缓存历史数据

### 7.3 性能优化
- 图表数据按需加载
- 虚拟滚动处理大量数据
- 防抖节流处理频繁操作
