\# SIM800C GSM/GPRS 模块用户手册（精简整理版） 本文档严格提取原手册核心内容，用于\*\*智能体固件开发、SIM800C 驱动编写\*\*参考，不含代码实现，仅保留硬件、指令、流程、状态等原始信息。  ---  ## 一、模块基础信息 ### 1. 模块概述 - 芯片：SIMCOM SIM800C - 频段：四频 850/900/1800/1900MHz（全球可用） - 功能：语音、SMS、数据、传真传输 - 兼容：移动/联通 2G/3G/4G 卡（兼容 GSM/GPRS） - 不支持：电信卡  ### 2. 核心硬件资源 - 电平：5V/3.3V TTL 电平自适应 - 供电：3.4V–4.4V 锂电池 / 5V USB（推荐 ≥500mA，峰值 2A） - 板载：1000μF 钽电容、SIM 卡 ESD 防护 - 接口：IPEX 天线、自弹式 SIM 卡槽、扩展排针 - 状态：NET\_STA 网络指示灯  ---  ## 二、硬件操作规范 ### 1. 开关机方式 - \*\*手动开关机\*\*：PWK 引脚与 GND 短路 \*\*≥1s\*\* 后松开 - \*\*开机自启动\*\*：PWK 与 GND 直接短接  ### 2. 供电方式 1. \*\*锂电池供电（推荐）\*\*    - VBAT 接红线，GND 接黑线    - 推荐 18650 电池，大电流稳定 2. \*\*5V 排针供电\*\*    - 电脑 USB 需确认电压/电流足够    - 板载大电容可支撑瞬间 2A 功耗  ### 3. NET\_STA 指示灯状态 | 指示灯模式 | 模块工作状态 | |-----------|-------------| | 熄灭 | 未工作/未上电 | | 60ms 亮 / 800ms 灭 | 未找到网络 / 无 SIM 服务 | | 60ms 亮 / 3000ms 灭 | 已注册网络（正常） | | 60ms 亮 / 300ms 灭 | GPRS 数据通信中 |  ---  ## 三、串口调试基础（驱动必备） ### 1. 串口参数 - 波特率：\*\*自适应\*\*（上电第一条指令波特率即为通信波特率） - 推荐：9600 8N1 - 指令格式：ASCII 英文符号，必须以\*\*回车换行\*\*结尾  ### 2. 调试工具 - USB-TTL：CP2102/CH340/PL2303 - 串口软件：SSCOM33 - 必须勾选：\*\*发送新行\*\*  ### 3. 基础接线（TTL 对接） - USB-TTL TXD → SIM800C RXD - USB-TTL RXD → SIM800C TXD - GND ↔ GND - VTTL 匹配 3.3V/5V 电平逻辑  ---  ## 四、基础 AT 指令集（原手册完整版） ### 1. 通用基础指令 | 指令 | 功能 | 典型返回 | |------|------|----------| | AT | 通信测试 | OK | | ATE1 | 开启指令回显（调试用） | OK | | ATE0 | 关闭指令回显（程序用） | OK | | AT+CPIN? | 查询 SIM 卡状态 | +CPIN:READY | | AT+CSQ | 查询信号强度（0–31） | +CSQ: 24,0 | | AT+COPS? | 查询当前运营商 | +COPS:0,0,"CHINA MOBILE" | | AT+CGMI | 查询厂商 | SIMCOM\_Ltd | | AT+CGMM | 查询型号 | SIMCOM\_SIM800 | | AT+CGSN | 查询 IMEI | 86676202xxxxxxxxxx | | AT+CNUM | 查询本机号码 | +CNUM: "","+861xxxxxxxxxx",145 |  ---  ## 五、通话功能 AT 指令 ### 1. 通话控制 | 指令 | 功能 | |------|------| | ATDxxxxxx; | 拨打电话（\*\*末尾必须加 ;\*\*） | | ATA | 接听来电 | | ATH | 挂断通话 |  ### 2. 号码显示 - AT+CLIP=1：开启来电显示 - AT+COLP=1：开启被叫号码显示  ### 3. 来电提示 - 来电时串口输出：\`RING\` - 带号码：\`+CLIP:"183xxxxxxxxx",161,",,",0\` - 挂断返回：\`NO CARRIER\`  ---  ## 六、短信功能 AT 指令 ### 1. 短信基础配置 | 指令 | 功能 | |------|------| | AT+CMGF=1 | 设置为\*\*文本模式\*\* | | AT+CMGF=0 | 设置为 PDU 模式 | | AT+CSCS="GSM" | 设置英文短信字符集 | | AT+CSCS="UCS2" | 设置中英文 Unicode 字符集 | | AT+CNMI=2,1 | 开启新短信提示 | | AT+CSMP=17,167,2,25 | 中文短信参数 | | AT+CSMP=17,167,0,8 | 兼容卡中文参数 |  ### 2. 短信操作 | 指令 | 功能 | |------|------| | AT+CMGR=X | 读取第 X 条短信 | | AT+CMGS="手机号" | 发送短信（返回 > 后输入内容） | | AT+CPMS? | 查询短信存储容量/已用 |  ### 3. 短信发送规则 - 英文：GSM 模式，直接发送字符串，结尾 \*\*0x1A\*\* 发送 - 中文：UCS2 模式，号码与内容必须转 Unicode，长度为 4 的倍数 - 发送结束符：\*\*十六进制 1A（Ctrl+Z）\*\*  ### 4. 新短信提示 - 格式：\`+CMTI:"SM",X\`（X 为存储位置）  ---  ## 七、GPRS / TCP / UDP 功能 ### 1. GPRS 基础配置 | 指令 | 功能 | |------|------| | AT+CGCLASS="B" | 设置移动台类别 B | | AT+CGDCONT=1,"IP","CMNET" | 设置 PDP 上下文 | | AT+CGATT=1 | 附着 GPRS 业务 | | AT+CIPCSGP=1,"CMNET" | GPRS 连接模式 |  ### 2. TCP 连接 | 指令 | 功能 | |------|------| | AT+CLPORT="TCP","端口" | 设置本地 TCP 端口 | | AT+CIPSTART="TCP","IP","端口" | 建立 TCP 连接 | | AT+CIPSEND | 发送数据（返回 > 后输入） | | AT+CIPCLOSE=1 | 关闭 TCP 连接 | | AT+CIPSHUT | 关闭移动场景 | | AT+CIPSTATUS | 查询连接状态 |  ### 3. UDP 连接 | 指令 | 功能 | |------|------| | AT+CLPORT="UDP","端口" | 设置本地 UDP 端口 | | AT+CIPSTART="UDP","IP","端口" | 建立 UDP 连接 |  ### 4. 域名连接 TCP - AT+CIPMUX=0：单连接 - AT+CIPRXGET=0：自动获取数据 - AT+CIPMODE=0：非透明模式 - AT+CIPSTART="TCP","域名","端口"  ### 5. 数据发送规则 - 数据输入完成后，发送 \*\*0x1A\*\* 启动发送 - 返回：\`SEND OK\` 表示发送成功 - TCP 需要\*\*心跳保活\*\*，否则会被运营商断开  ---  ## 八、使用流程（原手册标准流程） ### 1. 上电启动流程 1. 安装 SIM 卡、接天线 2. PWK 短接 GND 实现自启动 3. 供电（锂电池/5V） 4. 等待 NET\_STA 变为 60ms/3000ms 闪烁 5. 串口发送 AT → 返回 OK 通信正常  ### 2. 短信发送流程 1. AT+CMGF=1 2. AT+CSCS="GSM" / "UCS2" 3. AT+CNMI=2,1 4. AT+CMGS="手机号" 5. 输入内容 6. 发送 0x1A  ### 3. TCP 连接流程 1. GPRS 附着配置 2. 设置本地端口 3. 连接服务器 IP/端口 4. AT+CIPSEND 发送数据 5. 使用完毕关闭连接与场景  ---  ## 九、关键注意事项（驱动必看） 1. \*\*SIM 卡\*\*：仅支持移动/联通，不支持电信 2. \*\*供电\*\*：峰值电流大，必须保证稳定供电 3. \*\*指令\*\*：必须英文符号，结尾必须回车换行 4. \*\*短信\*\*：中文必须用 Unicode，发送 0x1A 5. \*\*TCP\*\*：无公网 IP 需用花生壳映射 6. \*\*电平\*\*：3.3V 与 5V 系统可自适应，无需电平转换 7. \*\*异常\*\*：PDP:DEACT 需执行 AT+CIPSHUT 才能重连  --
