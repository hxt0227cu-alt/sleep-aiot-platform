## 2. 数据帧格式 ⭐⭐⭐

### 2.1 帧结构定义

| 字段 | 长度 | 说明 |
|:---|:---|:---|
| **帧头** | 2 Byte | 固定 `0x53 0x59` |
| **控制字** | 1 Byte | 功能分类标识 |
| **命令字** | 1 Byte | 具体命令标识 |
| **长度标识** | 2 Byte | 数据域长度（高字节在前） |
| **数据** | n Byte | 实际数据内容 |
| **校验码** | 1 Byte | 累加和校验（低8位） |
| **帧尾** | 2 Byte | 固定 `0x54 0x43` |

### 2.2 帧结构示意图
```

+--------+--------+--------+--------+--------+--------+--------+--------+
\| 帧头 | 控制字 | 命令字 | 长度H | 长度L | 数据 | 校验和 | 帧尾 |
\| 0x53 | | | | | | | 0x54 |
\| 0x59 | 1Byte | 1Byte | 1Byte | 1Byte | nByte | 1Byte | 0x43 |
+--------+--------+--------+--------+--------+--------+--------+--------+

```

### 2.3 校验码计算方式
**校验码 = (帧头 + 控制字 + 命令字 + 长度标识 + 数据) 的和，取低8位**

> 示例：  
> 数据：`0x53 + 0x59 + 0x80 + 0x81 + 0x00 + 0x01 + 0x0F = 0x01BD`  
> 校验码：`0xBD`

## 6. 数据解析示例 ⭐⭐

### 6.1 示例1：存在信息查询

**构造查询指令：**
```

帧头： 53 59
控制字： 80
命令字： 81
长度： 00 01
数据： 0F
校验和计算：53+59+80+81+00+01+0F = 01BD → 取低字节 BD
帧尾： 54 43

完整指令：53 59 80 81 00 01 0F BD 54 43

```

**回复示例（有人）：**
```

53 59 80 81 00 01 01 25 54 43

```
解析：
- 帧头：53 59 ✓
- 控制字：80（人体存在）
- 命令字：81（存在信息回复）
- 长度：00 01（1字节数据）
- 数据：01（有人）
- 校验和：57（0x53+0x59+0x80+0x81+0x00+0x01+0x01=0x0157，取低字节0x57）
- 帧尾：54 43

### 6.2 示例2：呼吸数值上报

```

53 59 81 02 00 01 12 XX 54 43

```
解析：
- 控制字：81（呼吸检测）
- 命令字：02（呼吸数值）
- 数据：12（18次/分钟）

### 6.3 示例3：心率波形数据

```

53 59 85 05 00 05 7A 80 85 7F 82 XX 54 43

```
解析：
- 控制字：85（心率监测）
- 命令字：05（心率波形）
- 长度：00 05（5字节数据）
- 波形数据：7A(122) 80(128) 85(133) 7F(127) 82(130)
- 实际波形值（减去128）：-6, 0, +5, -1, +2

### 6.4 示例4：睡眠综合状态上报

```

53 59 84 0C 00 08 01 00 14 4B 02 0A 05 00 XX 54 43

```
解析：
- 控制字：84（睡眠监测）
- 命令字：0C（睡眠综合状态）
- 长度：00 08（8字节）
- 数据解析：
  - 字节1：01 = 有人
  - 字节2：00 = 深睡
  - 字节3：14 = 20次/分钟（呼吸）
  - 字节4：4B = 75 bpm（心跳）
  - 字节5：02 = 翻身2次
  - 字节6：0A = 大幅度体动占比10%
  - 字节7：05 = 小幅度体动占比5%
  - 字节8：00 = 呼吸暂停0次

## 8. 硬件设计注意事项

### 8.1 天线与外壳布局
- **PCBA**：雷达贴件高度需比其他器件高 **≥1mm**
- **外壳距离**：雷达天线面与外壳面保持 **2-5mm** 距离
- **外壳材质**：非金属材质，探测面需平直避免弯曲

### 8.2 静电防护
- 雷达内部具有静电敏感电路
- 避免用手触摸天线表面和连接器管脚
- 操作时建议佩戴防静电手套
