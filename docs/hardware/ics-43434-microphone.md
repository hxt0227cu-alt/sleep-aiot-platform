# ICS-43434 MEMS麦克风 驱动开发参考手册（精简版）
## 一、芯片概述
- **型号**：ICS-43434
- **类型**：底部进音、I²S数字输出MEMS麦克风
- **核心**：MEMS传感+信号调理+ADC+数字滤波+电源管理
- **位深**：**24位**，补码、MSB先行
- **模式**：高性能模式/低功耗模式/睡眠模式
- **封装**：6引脚LGA，**3.50mm×2.65mm×0.98mm**
- **工作温度**：-40℃~+85℃
- **优势**：无需音频编解码器，可直连DSP/MCU，灵敏度±1dB无需系统校准

## 三、引脚定义（驱动核心）
### 1. 引脚封装（顶视图，端子面朝下）
1:WS → 2:LR → 3:GND → 4:SCK → 5:VDD → 6:SD

### 2. 引脚功能表
| 引脚 | 名称 | 类型 | 功能说明 |
|------|------|------|----------|
| 1 | WS | 输入 | I²S字选择（帧同步） |
| 2 | LR | 输入 | 声道选择；**内部100kΩ下拉**；低=左声道，高=右声道 |
| 3 | GND | 地 | 电源地+信号地 |
| 4 | SCK | 输入 | I²S位时钟 |
| 5 | VDD | 电源 | 供电，需就近加0.1μF去耦电容 |
| 6 | SD | 输出 | I²S串行数据输出，非输出时高阻 |

## 五、工作模式（驱动控制核心）
### 1. 高性能模式（HPM）
- 采样率：**23kHz~51.6kHz**
- 适用：高清录音、语音识别
- 电流：490μA@1.8V

### 2. 低功耗模式（LPM）
- 采样率：**6.25kHz~18.75kHz**
- 适用：AlwaysOn唤醒、环境音监测
- 电流：230μA@1.8V

### 3. 睡眠模式（Sleep）
- 采样率：**＜3.125kHz**
- 电流：12μA
- 输出：SD高阻
- 唤醒：时钟恢复后，输出稳定灵敏度需20ms

### 4. 待机模式
- SCK频率＜200kHz自动进入
- 建议：停止SCK+WS并拉低，降低漏电流

## 六、I²S数字接口（驱动时序核心）
### 1. 接口规格
- 格式：标准I²S，**24位补码**，MSB先行
- 帧结构：每帧**64个SCK周期**
- 数据输出：仅在对应声道时段驱动SD，其余高阻
- 声道配置：LR引脚决定左/右声道输出

### 2. 声道输出规则
- LR=低：WS下降沿后输出**左声道**数据
- LR=高：WS上升沿后输出**右声道**数据
- 多麦共用SD线：需加**100kΩ下拉电阻**释放总线

### 3. 时钟要求
- SCK占空比：40%~60%
- SCK周期：303ns~2500ns
- SCK高/低电平最小时间：50ns

## 八、数字滤波特性
1. **高通滤波器**
   - -3dB截止频率：**24Hz**，不随采样率变化
   - 作用：消除直流与低频干扰
2. **低通抽取滤波器**
   - 通带：0.417×fs
   - 通带纹波：±0.3dB
   - 阻带衰减：58dB
   - 48kHz采样时通带=20kHz

---

## 九、应用与布局要点（驱动硬件必备）
1. **电源去耦**
   - VDD引脚就近加**0.1μF X7R陶瓷电容**到GND
   - 电容走线短，无过孔，靠近芯片
2. **PCB设计**
   - 麦克风进音孔直径≥0.5mm，避开焊膏
   - 进音孔周围密封，防尘防水
3. **SD总线**
   - 多麦共用SD线时，加**100kΩ下拉电阻**
4. **焊接与防护**
   - 回流焊峰值温度：有铅215℃，无铅260℃
   - 禁止超声清洗，禁止向进音孔吹气/吸气
5. **可靠性**
   - ESD敏感，操作需防静电
   - 最大声压：160dB SPL，机械冲击10000g
