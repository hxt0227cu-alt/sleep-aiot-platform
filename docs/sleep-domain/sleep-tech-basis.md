# SLEEP_TECH_BASIS.md
非接触睡眠监测技术原理、能力与局限性说明

## 1. 监测核心原理
设备搭载毫米波雷达传感器，不需要穿戴手环、传感器。
雷达发射高频电磁波，照射人体后接收反射信号；通过分析胸腔微弱起伏、身体微小晃动，算法解算出：
- 身体体动情况；
- 呼吸带来的胸廓位移；
- 根据周期性体征变化估算静息心率；
依靠持续体征变化特征划分浅睡、深睡、觉醒状态。

## 2. 优势
- 无穿戴束缚，不需要充电手环、传感器；
- 不产生图像，不存在画面隐私泄露；
- 长期夜间睡眠监测体验更好。

## 3. 技术局限（重要）
1. 属于**估算值**，和医用专业监护设备存在精度差距；
2. 厚棉被、金属遮挡会削弱雷达信号，影响识别准确度；
3. 床上存在第二个人、宠物持续活动时，容易干扰体征识别；
4. 无法直接识别血氧、血压等指标，不支持睡眠呼吸暂停病症筛查。

## 4. 适用定位
本技术面向普通消费者居家睡眠趋势长期记录，定位健康消费级产品，不属于医疗检测设备，指标结果仅作日常参考。
