# SLEEP_HEALTH_GUIDE.md
睡眠指标解读与健康参考指南

⚠️ 免责提示：本设备仅用于日常睡眠趋势参考，不属于医疗设备，不能用于疾病诊断、诊疗。出现持续身体不适请及时前往正规医疗机构就诊。

## 1. 睡眠阶段基础说明
一次完整夜间睡眠循环分为：浅睡、深睡、REM 快速眼动睡眠，整夜交替循环 4～6 轮。
1. 浅睡：入睡初期阶段，身体放松，容易惊醒，占成人夜间睡眠 45%～55%；
2. 深睡：深度休息阶段，身体修复、免疫力恢复，成人参考占比 15%～25%；
3. REM 快速眼动睡眠：大多和梦境相关，参与情绪整理、记忆巩固，成人参考占比 20%～25%。

> 注意：占比标准为普通健康成年人参考区间，年龄、作息、体质不同会存在个体差异，单次波动无需过度紧张，建议长期观察趋势。

## 2. 核心监测指标参考范围（静息夜间睡眠状态）
### 2.1 心率（静息睡眠心率）
- 健康成年人夜间静息睡眠心率参考：50～70 次/分钟；
- 经常运动人群、耐力爱好者睡眠心率可能低至 45～55 次/分，多数属于正常个体差异；
- 持续长时间＞90 次/分，或持续低于 45 次/分，并伴随胸闷、头晕、心慌，建议线下就医评估。

### 2.2 呼吸率
- 成人睡眠状态正常呼吸频率：12～20 次/分钟；
- 短时间轻微波动属于正常翻身、睡姿变动导致；
- 频繁出现呼吸长时间中断、呼吸节律忽快忽慢，可重点持续观察。

## 3. 睡眠报告常用指标解读
### 3.1 睡眠效率
睡眠效率 = 实际睡眠时间 / 卧床总时长
参考理想区间：≥85%
偏低常见诱因：入睡困难、频繁夜醒、卧床长时间玩手机。

### 3.2 入睡潜伏期（入睡时长）
卧床到进入睡眠的时长：正常参考 10～30 分钟；
小于 5 分钟：多提示身体过度疲惫；
超过 40 分钟持续多晚，属于入睡困难表现。

### 3.3 夜间觉醒次数
健康人群夜间可能有短暂微觉醒（自身大多无感知）；
频繁长时间清醒、多次醒来难以再次入睡，会明显影响睡眠质量。

## 4. 通用睡眠改善建议
1. 尽量固定起床与入睡时间，包含周末，维持稳定生物钟；
2. 睡前 1 小时减少手机、强光屏幕刺激；
3. 卧室保持偏暗、安静、适宜温度，推荐室温 22～26℃；
4. 下午 3 点后避免咖啡、浓茶、功能性饮料；
5. 规律日间轻度运动，避免临睡前剧烈运动。

## 5. 辅助功能说明：白噪音助眠
白噪音能够掩盖环境突发杂音，降低外界干扰带来的惊醒概率，帮助部分人群稳定情绪、辅助入睡；
白噪音属于环境辅助手段，不存在治疗效果，不同人感受差异较大，可以自行尝试对比效果。

## 6. 数据观测建议
单次一晚数据波动参考价值有限，建议连续观测 7～14 天睡眠趋势，长期变化比单日指标更具备参考意义。
