# ALARM_SAFETY_GUIDE.md
设备报警规则、触发逻辑与安全边界指南

⚠️ 免责提示：本设备仅做居家风险提醒，**不具备医疗预警、急救监测能力，不可替代监护仪与专业医护监护**。发生持续不适请立刻联系家属或就医。

## 1. 报警类型与基础触发逻辑
设备基于毫米波雷达采集的体动、呼吸、心率变化进行判断，主要报警分类：

体征类报警（基于雷达体征判断）：
1. 长时间静息异常提醒：长时间未监测到明显体动与稳定呼吸节律；
2. 呼吸节律异常提醒：短时间内呼吸频率持续偏高/偏低、节律波动剧烈；
3. 心率异常提醒：睡眠中心率持续偏离常规区间；
4. 离床提醒：监测对象长时间离开床铺。

系统类报警（与体征无关，详见用户手册 9.1）：
- 体动异常：体动过于频繁；
- 设备离线：设备失去连接；
- 低电量：设备电量过低。

> 重要：雷达易受被褥厚度、睡姿、床上杂物、环境遮挡干扰，报警存在误报可能性，仅作为辅助提醒。

## 2. 紧急联系人通知流程
开启联系人推送功能后：
1. 本地设备先进行声光提示；
2. 达到设定持续时长条件后，系统推送消息至绑定的紧急联系人；
用户可在 APP 内自由开启/关闭各类报警、自定义报警等待时长。

## 3. 如何区分普通波动与需要就医的情况
下述仅作为参考判断方向，不能作为诊断依据：
✅ 无需紧张：仅仅一晚指标异常，次日精神状态正常，无胸闷、憋气、头晕不适；
⚠️ 需要重视，建议及时就诊：连续多晚反复触发异常报警，白天持续伴随心慌、气短、嗜睡、晨起头痛、夜间憋醒等感受。

## 4. 使用红线与边界
1. 不建议将本设备作为重症病人、失能人员、睡眠呼吸暂停患者的唯一监护工具；
2. 报警功能无法保证 100% 不漏报，不能替代专人看护；
3. 若收到报警通知，优先电话确认本人状态，条件允许及时上门查看；
4. 任何身体持续不适，优先选择联系医疗机构，不要单纯依靠设备报警判断。

## 5. 常见误报诱因
- 厚被子遮挡雷达信号；
- 床上堆放大量衣物、抱枕；
- 床铺频繁震动、附近大功率电器干扰；
- 翻身幅度小，雷达难以识别生命体征变化。
