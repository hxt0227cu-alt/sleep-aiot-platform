## 1. 产品介绍

### 1.1 产品概述

智能睡眠监测台灯是一款集睡眠监测、智能照明、语音控制于一体的智能家居设备。通过毫米波雷达技术，非接触式监测用户的睡眠状态，提供专业的睡眠分析报告。

### 1.2 核心功能

- **睡眠监测**: 实时监测心率、呼吸率、体动等生命体征
- **智能照明**: 支持亮度、色温调节，多种场景模式
- **光闹钟**: 渐变唤醒，自然唤醒体验
- **语音控制**: 支持语音指令控制设备
- **白噪音**: 内置多种白噪音，助眠放松
- **负离子**: 释放负离子，净化空气
- **OTA升级**: 支持远程固件升级

### 1.3 技术参数

| 参数 | 规格 |
|------|------|
| 雷达类型 | R60ABD1 毫米波雷达 |
| 监测距离 | 0-2米 |
| 功率 | 12W |
| 输入电压 | 100-240V AC |
| 色温范围 | 2700K-6500K |
| 亮度范围 | 0-100% |
| 通信方式 | Wi-Fi + MQTT |
| 工作温度 | -10°C ~ 45°C |

## 3. 设备绑定

### 3.1 扫码绑定

1. 确保设备已通电
2. 长按设备按钮3秒进入配网模式
3. 在小程序中点击"扫码绑定"
4. 扫描设备上的二维码
5. 确认设备信息
6. 输入设备名称（如：卧室）
7. 点击"确认绑定"

### 3.2 手动绑定

1. 在设备标签上找到设备ID和绑定码
2. 在小程序中点击"手动绑定"
3. 输入设备ID
4. 输入绑定码
5. 输入设备名称
6. 点击"确认绑定"

### 3.3 绑定成功

绑定成功后，设备将显示在设备列表中，您可以：
- 查看设备在线状态
- 控制设备功能
- 查看设备数据
- 管理设备设置

## 5. 睡眠监测

### 5.1 实时监测

在首页可以实时查看：
- **心率**: 当前心率值（次/分钟）
- **呼吸率**: 当前呼吸率（次/分钟）
- **体动**: 体动强度
- **睡眠状态**: 当前睡眠状态（清醒/浅睡/深睡）

### 5.2 历史数据

1. 点击底部"历史"标签
2. 选择时间范围（今天/本周/本月）
3. 查看各项指标趋势图：
   - 心率趋势图
   - 呼吸率趋势图
   - 体动趋势图
   - 睡眠分期图

### 5.3 睡眠报告

1. 在历史数据页面点击某一天
2. 查看详细睡眠报告：
   - 睡眠评分
   - 睡眠时长
   - 睡眠结构
   - 睡眠指标
   - 健康建议

### 5.4 睡眠评分说明

睡眠评分基于以下维度：
- **睡眠时长**: 实际睡眠时间
- **睡眠效率**: 睡眠时间/在床时间
- **深睡比例**: 深睡时间占比
- **入睡时长**: 从躺下到入睡的时间
- **觉醒次数**: 夜间觉醒次数
- **心率稳定性**: 心率变化幅度

评分范围：0-100分
- 90-100分：优秀
- 80-89分：良好
- 70-79分：一般
- 60-69分：较差
- 0-59分：很差

## 6. 灯光控制

### 6.1 开关控制

1. 在首页找到灯光控制卡片
2. 点击开关按钮
3. 灯光将立即开启或关闭

### 6.2 亮度调节

1. 在灯光控制页面
2. 拖动亮度滑块
3. 亮度范围：0-100%
4. 松开滑块后自动保存

### 6.3 色温调节

1. 在灯光控制页面
2. 拖动色温滑块
3. 色温范围：2700K-6500K
   - 2700K：暖光（适合睡前）
   - 4000K：自然光（适合阅读）
   - 6500K：冷白光（适合工作）

### 6.4 场景模式

当前首页与独立灯光页的预设参数尚未统一。界面会显示各页面实际采用的亮度和色温；统一前不应把某一组数值视为跨页面产品标准。

### 6.5 定时关闭

1. 在灯光控制页面
2. 点击"设置定时关闭"
3. 选择预设时间（15/30/60/120分钟）
4. 或输入自定义时间
5. 点击"确定"

## 7. 闹钟设置

### 7.1 添加闹钟

1. 点击底部"我的"标签
2. 点击"闹钟设置"
3. 点击"+"按钮
4. 设置闹钟参数：
   - 闹钟名称
   - 闹钟时间
   - 重复周期
   - 光闹钟设置
   - 声音设置
5. 点击"保存"

### 7.2 光闹钟设置

光闹钟通过渐变灯光唤醒：
- **启用光闹钟**: 开启/关闭光闹钟功能
- **渐亮时长**: 当前可选 10/15/20/30 分钟
- **目标亮度**: 唤醒时的目标亮度（50-100%）
- **目标色温**: 唤醒时的色温（4000-6500K）

### 7.3 闹钟管理

- **编辑闹钟**: 点击闹钟卡片进入编辑
- **删除闹钟**: 长按闹钟卡片删除
- **启用/禁用**: 点击开关启用或禁闹钟
- **重复周期**: 设置闹钟重复（工作日/周末/每天）

## 8. 语音控制

### 8.1 开启语音控制

1. 点击底部"我的"标签
2. 点击"语音设置"
3. 开启"语音开关"
4. 设置唤醒词（默认：小台灯）

### 8.2 语音指令

支持的语音指令：
- **开灯/关灯**: 控制灯光开关
- **调亮/调暗**: 调节亮度
- **开负离子/关负离子**: 控制负离子
- **播放白噪音**: 播放白噪音
- **停止白噪音**: 停止白噪音
- **设置闹钟**: 设置闹钟
- **查看睡眠**: 查看睡眠数据

### 8.3 使用方法

1. 确保语音控制已开启
2. 清晰地说出唤醒词（如："小台灯"）
3. 等待设备回应
4. 说出语音指令
5. 设备执行指令并反馈

### 8.4 白噪音

固件当前随工程提供的音频文件：
- **雨声**: `rain.wav`
- **风声**: `wind.wav`
- **鸟鸣**: `bird.wav`
- **雷声**: `thunder.wav`

音频版权和真实设备播放效果仍需在正式发布前验证。

## 9. 报警管理

### 9.1 报警类型

系统支持以下报警：
- **心率异常**: 心率过高或过低
- **呼吸异常**: 呼吸停止或异常
- **体动异常**: 体动过于频繁
- **设备离线**: 设备失去连接
- **低电量**: 设备电量过低

### 9.2 查看报警

1. 点击底部"报警"标签
2. 查看报警列表
3. 点击报警卡片查看详情
4. 可以标记为已处理

### 9.3 报警设置

1. 在"我的"页面点击"报警设置"
2. 配置报警参数：
   - 心率上限/下限
   - 呼吸率上限/下限
   - 报警推送开关
   - 紧急联系人

### 9.4 紧急联系人

1. 在"我的"页面点击"紧急联系人"
2. 点击"添加联系人"
3. 填写联系人信息：
   - 姓名
   - 手机号
   - 关系
4. 点击"保存"

## 10. 常见问题

### Q1: 设备无法连接？

**解决方案**:
1. 检查设备是否通电
2. 检查Wi-Fi网络是否正常
3. 确认设备在配网模式
4. 重新绑定设备

### Q2: 睡眠数据不准确？

**解决方案**:
1. 检查设备安装位置
2. 确保监测范围内无障碍物
3. 调整设备高度和角度
4. 避免在设备附近活动

### Q3: 灯光不响应？

**解决方案**:
1. 检查设备在线状态
2. 确认网络连接正常
3. 重启设备
4. 联系客服

### Q4: 语音控制不工作？

**解决方案**:
1. 检查语音控制是否开启
2. 确认唤醒词设置正确
3. 清晰地说出指令
4. 检查环境噪音是否过大

### Q5: 如何更新固件？

**解决方案**:
1. 在"我的"页面点击"设备详情
2. 点击"检查更新"
3. 如有新版本，点击"开始升级"
4. 等待升级完成

### Q6: 如何联系客服？

**联系方式**:
- 客服电话：400-XXX-XXXX
- 客服邮箱：support@sleep-lamp.com
- 在线客服：小程序内"帮助与反馈"
