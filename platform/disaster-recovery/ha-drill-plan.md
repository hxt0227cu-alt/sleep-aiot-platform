# 灾难恢复演练计划

## 概述

**演练频率**: 每季度一次
**演练时长**: 4小时
**参与人员**: 运维团队、开发团队、DBA、安全团队
**演练目标**: 验证灾难恢复流程的有效性，确保 RTO/RPO 达标

## 演练场景

### 场景 1: 单可用区故障（1小时）

**模拟故障**:
- 阿里云深圳可用区 A 完全故障
- 该可用区的所有 ECS/RDS/Redis 不可用

**验证目标**:
- RTO < 15分钟
- RPO < 5分钟
- 服务自动切换到可用区 B/C

**演练步骤**:
1. 准备阶段（15分钟）
   - 确认当前服务状态正常
   - 记录当前连接数和流量
   - 通知相关团队

2. 故障注入（5分钟）
   - 通过安全组规则阻断可用区 A 的流量
   - 或停止可用区 A 的 ECS 实例

3. 观察和恢复（30分钟）
   - 观察服务自动切换情况
   - 记录 RTO（服务恢复时间）
   - 验证数据完整性（RPO）
   - 检查负载均衡器是否正常分发流量

4. 恢复阶段（10分钟）
   - 恢复可用区 A 的服务
   - 观察流量是否自动回切

### 场景 2: 数据库主库故障（1小时）

**模拟故障**:
- PostgreSQL 主库节点崩溃
- 无法连接主库

**验证目标**:
- RTO < 5分钟
- RPO = 0（同步复制）
- 从库自动提升为主库

**演练步骤**:
1. 准备阶段（10分钟）
   - 确认主从复制状态正常
   - 记录当前数据库连接数

2. 故障注入（2分钟）
   - 停止 PostgreSQL 主库 Pod
   - `kubectl delete pod postgres-0 -n database`

3. 观察和恢复（20分钟）
   - 观察从库是否自动提升
   - 记录 RTO
   - 验证应用是否自动重连
   - 检查数据一致性

4. 恢复阶段（15分钟）
   - 原主库恢复后转为从库
   - 验证主从复制正常

### 场景 3: 整个集群故障（1小时）

**模拟故障**:
- 整个 Kubernetes 集群不可用
- 需要从备份恢复到备用集群

**验证目标**:
- RTO < 30分钟
- RPO < 1小时
- 备用集群可正常提供服务

**演练步骤**:
1. 准备阶段（15分钟）
   - 确认备份最新且可用
   - 确认备用集群环境就绪
   - 通知所有相关团队

2. 故障注入（5分钟）
   - 停止主集群的所有服务
   - 或切换 DNS 到备用集群

3. 恢复阶段（30分钟）
   - 在备用集群恢复数据库
   - 恢复应用服务
   - 验证服务可用性
   - 记录 RTO 和 RPO

4. 回切阶段（10分钟）
   - 主集群恢复后，切回主集群
   - 同步增量数据

### 场景 4: 数据误删除（1小时）

**模拟故障**:
- 误操作删除了生产数据库的重要数据
- 需要从备份恢复

**验证目标**:
- RTO < 1小时
- RPO < 5分钟（基于 PITR）
- 数据完整恢复

**演练步骤**:
1. 准备阶段（10分钟）
   - 确认 PITR（时间点恢复）功能正常
   - 选择测试表进行演练

2. 故障注入（5分钟）
   - 删除测试表的数据
   - `DELETE FROM test_table WHERE created_at < '2026-01-01';`

3. 恢复阶段（30分钟）
   - 使用 PITR 恢复到删除前的时间点
   - 验证数据完整性
   - 记录 RTO

4. 清理阶段（15分钟）
   - 清理测试数据
   - 确认生产数据未受影响

## 演练检查清单

### 演练前检查

- [ ] 所有团队已通知
- [ ] 备份已验证可用
- [ ] 备用环境已就绪
- [ ] 监控告警已配置
- [ ] 通信渠道已建立（飞书群）
- [ ] 演练计划已审批

### 演练中记录

- [ ] 故障注入时间
- [ ] 服务恢复时间（RTO）
- [ ] 数据丢失量（RPO）
- [ ] 遇到的问题
- [ ] 手动干预步骤
- [ ] 各阶段耗时

### 演练后检查

- [ ] 所有服务已恢复正常
- [ ] 数据完整性已验证
- [ ] 监控指标已恢复正常
- [ ] 临时变更已回滚
- [ ] 演练报告已完成

## 演练评估标准

| 指标 | 目标 | 优秀 | 合格 | 不合格 |
|------|------|------|------|--------|
| RTO（单可用区） | < 15分钟 | < 5分钟 | < 15分钟 | > 15分钟 |
| RTO（数据库） | < 5分钟 | < 2分钟 | < 5分钟 | > 5分钟 |
| RTO（全集群） | < 30分钟 | < 15分钟 | < 30分钟 | > 30分钟 |
| RPO（单可用区） | < 5分钟 | < 1分钟 | < 5分钟 | > 5分钟 |
| RPO（数据库） | = 0 | = 0 | < 1分钟 | > 1分钟 |
| 自动化程度 | > 80% | > 95% | > 80% | < 80% |
| 文档完整性 | 完整 | 完整 | 基本完整 | 缺失 |
